# 项目缘起

[← 返回项目首页](../README.md)

这个项目起于三年左右的反复试用。我在中英文模型里跑长上下文角色扮演，也参与中文 RP 社区讨论，慢慢积下一批很难说清的阅读失望：句子通顺，角色还在说话，可关系、压力或场景的气已经被悄悄改掉。

最初的兴趣来自几条交叉的线。国产乙女游戏让我看到恋爱模拟的吸引力，也留下对角色可定制性的遗憾；GPT-4o 和 Character.AI 网页版的变化，则让我持续观察文字角色扮演能力如何移动。长期阅读和写作提供了另一把尺子。

曾有读者把我参与推演的曹丕心理侧写手抄下来，带到墓前。那件小事让我意识到，虚构文字会在历史人物、读者、角色与机器之间建立一种很具体的连接。

Atlas 想给这些失望一套可复查的语言。它从“读起来顺，但某个地方就是不对”出发，把感受拆成症状、边界测试和修订目标。v2 又向前走了一步：机器生成诊断证据、提出修订、执行盲测，再按预设规则决定是否晋升；人工观察和否决仍可接入，但不占据每次运行的必经节点。

## 证据边界

这些观察主要来自我自己的试用和写作，外加社区交流，样本远不足以代表整个市场。中英文 RP 的差异哪些能稳定复现，还得换模型、换场景、换评审者反复测。

当前分类法与协议都是实验设计。“可运行”只说明记录和 Gate 能执行；失效模式、偏差传播、奖励投机及真实修订收益都要继续测量。
