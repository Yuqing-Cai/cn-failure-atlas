# 项目缘起

[← 返回项目首页](../README.md)

这个项目来自我约三年间对中英文长上下文角色扮演的持续试用：我想把一些反复出现、却很难说清的阅读失望，整理成可以命名、讨论和复查的语言。

起点是三类个人经验的交叉：国产乙女游戏带来的恋爱模拟体验，以及对角色可定制性的遗憾；试用 GPT-4o 和 Character.AI 网页版时感受到的文字角色扮演能力变化；还有长期阅读与写作形成的敏感。曾有读者把我参与推演的曹丕心理侧写手抄后带到墓前——这件小事让我更在意文字如何连接历史人物、读者、虚构角色与机器。这里记录的是项目动机，不是对市场规模、用户偏好或模型能力的抽样结论。

这期间我在若干中英文模型上反复进行长上下文角色扮演，也参与过中文 RP 社区讨论。在我接触的样本中，中英文 RP 的文化语境和叙事惯例确有差异，一些中文场景也更容易暴露特定问题；这些观察来自目的性试用与社区经验，尚不能代表完整市场或全部模型。

这套分类体系不是一份已经验证的学术结论，而是一套实验性诊断词汇与协议。它试图把“读起来顺，但某个地方就是不对”的感受转成可检查的症状、边界测试和修订目标。它能否稳定区分模型、提高修订成功率、适用于哪些中文虚构类型，都需要后续基准、重复实验和跨评审者研究来回答。

v2 尝试把这份词汇表扩展为纯机器自我纠错协议：机器生成诊断证据、提出修订、执行盲测并依据预设规则决定是否晋升；人类可观察、抽查和否决，但不被设为每次运行的必经节点。当前版本仍是实验设计，“可运行”不等于已经证明它能可靠自我改进，也不等于取消对失效模式、偏差传播和奖励投机的验证。
